# Muhammad Fathurrahman — Portfolio

Personal developer portfolio hosted on GitHub Pages at [fyou00.github.io](https://fyou00.github.io/), featuring a warm brown (`#854836`) **Dark Espresso & Warm Latte Glassmorphism** design system.

## Features
- **Dual Glassmorphism Themes:** Switch between **Dark Espresso** (default) and **Warm Latte** light mode with preference saved in `localStorage`.
- **Responsive Bento & Grid Layout:** Built with semantic HTML5, modern CSS Grid/Flexbox, and zero CSS framework bloat.
- **Interactive Portfolio Showcase:** Category filters (`All`, `Web App`, `Game`, `Landing Page`, `Mobile`) and a glassmorphic project detail modal.
- **Direct Contact Flow:** Working `mailto:` link with one-click copy-to-clipboard toast, Google Maps location link, and a WhatsApp quick-message composer.
- **Accessibility:** Proper heading hierarchy, ARIA labels, keyboard-accessible modal (`Esc` to close), focus rings, and `prefers-reduced-motion` support.

## Customization
- **Default Theme:** Change `data-theme="dark"` on `<html>` in `index.html` to `data-theme="light"` to default to Warm Latte mode.
- **Project Links:** Update the `link` field inside `PROJECT_DATA` in `script.js` to point each project to its specific repository or live demo.
